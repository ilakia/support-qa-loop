# Saving regular customers in the address book

If you deliver to the same customers often, save them in the address book. This saves typing and keeps the pin, apartment details and driver notes the same every time.

## Save a customer
1. Open a stop that is already correct, with the right pin and details.
2. Click **Save to address book**.
3. Give the entry a short name, for example "Bakery Krause".

## Use a saved customer
When you create a new stop, type the saved name in the **Address** field. Address book entries appear at the top of the suggestion list with a star icon. Picking one fills in the address, pin, recipient, phone number, address details and driver notes.

## Edit or delete entries
Go to **Settings > Address book**. Changes only affect new stops. Stops that were already created keep their old details.

## Who can do this
Dispatchers and Admins can use and edit the address book. The address book is shared by everyone in your company account.

## Limits
Each company account can save up to 5,000 address book entries.
